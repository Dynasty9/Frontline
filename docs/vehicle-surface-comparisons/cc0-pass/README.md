# CC0 texture integration: before and after

Before is the initial procedural material library; after is the CC0 integration. These show the incremental change, separate from the [original baseline comparison](../README.md).

The clearest correction is the painted cargo drums: they no longer sparkle like bare metal. Grain and roughness changes on bodywork are intentionally subtle. The RHIB has a treaded deck; the gun trawler uses oxidation on selected existing rust patches and anchors. Geometry and lighting still limit how realistic the vehicles look.

## Close-ups

Identical seed 3, studio lighting, bounds-fit orthographic camera and Godot 4.6.3 Compatibility. Before captured from e31ed14; after from the CC0 integration working tree.
